🔍 Code Pattern Recognition

Universal DP Pattern:
1. Base Case: What happens when we have 0 items or 0 capacity?
2. Choice: For each item, we have 2 options - include it or exclude it
3. Optimal: Pick the better option (max for knapsack, OR for subset sum)
// Universal DP Template if (baseCase) return baseValue; if (cached) return cache[state]; if (canIncludeCurrentItem) { // Choice 1: Include current item include = value[current] + solve(remaining_items, reduced_capacity); // Choice 2: Exclude current item exclude = solve(remaining_items, same_capacity); result = chooseOptimal(include, exclude); } else { // Must exclude current item result = solve(remaining_items, same_capacity); } cache[state] = result; return result;
